# Machine Learning Notes

Supervised learning uses labeled examples. The model learns from inputs paired with known outputs, such as house features paired with sale prices or emails paired with spam labels.

Unsupervised learning works with unlabeled data. The goal is often to discover structure, such as clusters of similar customers or lower-dimensional representations of high-dimensional data.

Gradient descent is an optimization algorithm. It updates model parameters in the direction that reduces the loss function. The learning rate controls the size of each update.

Overfitting happens when a model learns the training data too closely and performs poorly on new data. Common ways to reduce overfitting include more training data, regularization, simpler models, dropout, and validation-based early stopping.

Evaluation should match the problem. Classification tasks often use accuracy, precision, recall, F1 score, and ROC-AUC. Regression tasks often use mean absolute error, mean squared error, and R-squared.
